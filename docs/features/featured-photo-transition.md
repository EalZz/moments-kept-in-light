# 메인 사진 전환 안정화

[전체 기능 안내](../../FEATURES.md) · [선택 업데이트 목록](../../updates/README.md)

**종류: 갤러리 표시 / 제공 형태: 선택 업데이트 1.0.0**

네트워크가 느리거나 사진을 연속으로 넘길 때, 이전 사진이 다시 나타나거나 사진과 설명이 어긋나는 문제를 줄이는 기능입니다.

## 어떤 기능인가요?

| 상황 | 업데이트 후 처리 |
|---|---|
| 다음 사진이 아직 로딩 중 | 현재 사진을 유지 |
| 다음 사진 준비 완료 | 사진과 설명을 함께 전환 |
| 연속 넘김 입력 | 진행 중인 전환을 보호 |
| 이미지 로딩 실패·시간 초과 | 미완성 사진으로 바꾸지 않고 현재 사진 유지 |

메인 사진의 자동 넘김과 수동 넘김에 적용하는 동작 개선입니다.

## 화면에서 사용하는 방법

1. 업데이트 적용 후 방문자 홈의 메인 사진을 엽니다.
2. 자동 넘김과 좌우 넘김을 확인합니다.
3. 느린 네트워크에서도 사진과 설명이 함께 바뀌는지 확인합니다.

## 적용 전 확인

별도 선행 업데이트가 없습니다. 이 기능만 선택해 적용할 수 있습니다.

현재 ZIP은 전환 동작을 개선합니다. 운영 사이트의 새 블러 배경·메인 레이아웃·인트로 이미지는 포함하지 않습니다.

검증 기준은 `c1e54c3` 배포 계열입니다. 다른 버전이나 개인 수정이 있으면 적용 전에 검사하거나 차이를 비교해야 합니다.
