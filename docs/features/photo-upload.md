# 사진 업로드·이미지 변환

[전체 기능 안내](../../FEATURES.md) · [설치 안내](../../SETUP.md)

**제공 형태: 기본 포함** — 기준 배포본 `c1e54c3`에 포함된 기능입니다. 별도 선택 업데이트 ZIP은 없습니다.

관리자 화면에서 사진을 추가하고, 웹 갤러리에 사용할 이미지와 촬영 정보를 준비합니다.

## 할 수 있는 일

- 사진을 끌어 놓거나 파일 선택으로 업로드합니다.
- 브라우저에서 large·medium·thumbnail 크기의 WebP 이미지를 생성합니다.
- 지원하는 사진 파일의 EXIF에서 카메라·렌즈·촬영 설정 등의 정보를 읽습니다.
- 업로드한 사진은 컬렉션이나 사람별 폴더에서 관리합니다.

## 사용하는 방법

1. `/admin`에서 대상 컬렉션을 엽니다.
2. 사진을 넣을 영역이나 사람별 폴더를 고릅니다.
3. 업로드 영역에 사진을 끌어 놓거나 클릭해 파일을 선택합니다.
4. 완료 상태와 추가된 사진을 확인합니다.

## 사용 예시·참고

예: 보정한 JPG를 모델 폴더에 넣으면 웹 표시용 크기를 준비해 올립니다. 원본 RAW 보관·전달을 대신하는 기능은 아닙니다.

[선택 업데이트 목록](../../updates/README.md)에서 관련 개선 기능도 확인할 수 있습니다.
