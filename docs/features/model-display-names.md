# 사람별 모델 표시 이름

[전체 기능 안내](../../FEATURES.md) · [선택 업데이트 목록](../../updates/README.md)

**종류: 모델·크레딧 / 제공 형태: 선택 업데이트 1.0.0**

여러 모델이 함께한 촬영에서 계정마다 다른 닉네임을 정확하게 표시하고 싶을 때 사용합니다.

## 어떤 기능인가요?

| 입력 | 표시 의도 |
|---|---|
| 계정 @model_a, 이름 모델 A | 첫 번째 사람의 표시 이름 |
| 계정 @model_b, 이름 모델 B | 두 번째 사람의 표시 이름 |
| 세션 이름 모델 A & 모델 B | 촬영 묶음을 설명하는 제목 |

세션 전체 이름과 사람별 이름을 구분합니다. 계정별 표시 이름을 저장하고 행사·개인 세션·모델 관련 화면에서 사용합니다.

## 화면에서 사용하는 방법

1. 관리자에서 폴더 정보나 개인 세션 정보를 엽니다.
2. 모델 계정을 입력합니다.
3. 사람별 표시 이름 입력란에서 각 계정의 이름을 확인하고 저장합니다.
4. 방문자 화면의 이름과 크레딧을 확인합니다.

## 적용 전 확인

별도 선행 업데이트는 없습니다. [트윗 정보 선택 가져오기](tweet-import-select.md)의 선행 기능입니다.

기존 이름은 입력한 정보와 저장 범위에 따라 유지됩니다. 전역 표시 이름과 폴더·세션별 이름이 있으므로 계정과 이름의 대응을 확인하세요.

검증 기준은 `c1e54c3` 배포 계열입니다. 다른 버전이나 개인 수정이 있으면 적용 전에 검사하거나 차이를 비교해야 합니다.
