# 트윗 정보 선택 가져오기

[전체 기능 안내](../../FEATURES.md) · [선택 업데이트 목록](../../updates/README.md)

**종류: 정보 가져오기 / 제공 형태: 선택 업데이트 1.0.0**

트윗의 계정·장르·캐릭터만 가져오고 기존 닉네임과 사진은 유지하고 싶을 때 사용합니다.

## 어떤 기능인가요?

| 항목 | 기본 선택 | 표시 예시 |
|---|---|---|
| 닉네임 | 해제 | 모델 A |
| 계정 | 선택 | @model_a |
| 장르(작품) | 선택 | 원신 |
| 캐릭터 | 선택 | 감우 |
| 사진 | 해제 | 사진 4장 |

계정은 게시물 작성자 계정이 아니라, 정해진 본문 형식의 `Model::` 줄에서 찾은 모델 계정입니다. 장르·캐릭터는 `작품 - 캐릭터` 형식에서 나눕니다. 모든 자유 형식 게시물을 자동으로 이해하는 기능은 아닙니다.

## 화면에서 사용하는 방법

1. 대상 폴더의 입력칸에 X 게시물 링크를 넣고 **트윗 정보 확인**을 누릅니다.
2. 추출한 값과 반영 위치를 확인합니다.
3. 가져올 항목을 체크하고 **선택한 정보 가져오기**를 누릅니다.
4. 사진은 체크했을 때만 업로드합니다. 취소하면 정보 저장과 업로드를 실행하지 않습니다.

## 적용 전 확인

먼저 [사람별 모델 표시 이름](model-display-names.md)을 적용해야 합니다. 갤러리나 사진 전환 업데이트는 필요하지 않습니다.

찾지 못한 항목은 선택할 수 없습니다. 사진 없는 게시물도 텍스트 정보 확인이 가능합니다. 행사 바로 아래에서 실행하면 새 폴더 생성 여부와 이름을 확인합니다.

검증 기준은 `c1e54c3` 배포 계열입니다. 다른 버전이나 개인 수정이 있으면 적용 전에 검사하거나 차이를 비교해야 합니다.
