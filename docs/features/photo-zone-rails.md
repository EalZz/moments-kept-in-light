# Photo Zone과 가로 세션 카드

[전체 기능 안내](../../FEATURES.md) · [선택 업데이트 목록](../../updates/README.md)

**선택 업데이트** · 먼저 [개인 세션 카드와 대표 사진 구도](personal-session-cards.md) 기능을 적용하세요.

사진사존처럼 행사에서 모델·팀별로 진행한 촬영을 `Photo Zone`에 따로 모읍니다. 메인의 `Personal Sessions`와 `Photo Zone`은 각각 가로 카드 줄로 표시합니다.

## 사용 방법

1. 관리자에서 새 컬렉션을 만들거나 기존 세션의 **컬렉션 메뉴 → 정보 수정**을 엽니다. **촬영 유형**을 **Photo Zone**으로 선택합니다.
2. 필요하면 **관련 행사**를 선택하고 사진·대표 사진을 지정한 뒤 공개합니다. 연결한 행사의 상세에서도 세션을 열 수 있습니다.
3. 관리자 목록의 `Personal Sessions`에 해당하는 **개인 세션** 목록과 **Photo Zone** 목록에서 `▲▼`로 각 줄의 카드 순서를 바꿉니다.
4. 메인에서 PC는 마우스를 올려 자동 이동을 멈추고 휠로 한 카드씩 넘깁니다. 모바일은 손가락을 대면 멈추고, 스와이프하면 다음 카드가 중앙에 맞습니다.

## 사용 예시

코믹월드에서 사진사존으로 촬영한 세 팀을 각각 공개하면, 메인 Photo Zone과 코믹월드 상세에서 같은 세션을 열 수 있습니다.
