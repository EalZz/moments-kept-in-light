# 행사·개인 세션 정리

[전체 기능 안내](../../FEATURES.md) · [설치 안내](../../SETUP.md)

**제공 형태: 기본 포함** — 기준 배포본 `c1e54c3`에 포함된 기능입니다. 별도 선택 업데이트 ZIP은 없습니다.

촬영 단위로 사진을 나누고, 행사에서 여러 모델을 찍은 경우와 한 명·한 팀의 개인 촬영을 구분합니다.

## 할 수 있는 일

- **행사(Event)**: 행사 컬렉션 안에 사람별 폴더를 만들어 사진을 정리합니다.
- **개인 세션(Personal Session)**: 별도 사람 폴더 없이 컬렉션에 모델·계정·캐릭터·작품 정보를 입력합니다.
- **관련 행사 연결**: 행사 중 진행한 개인 촬영은 관련 행사로 연결할 수 있습니다. 두 컬렉션은 각각 유지됩니다.
- **촬영 장소**: 행사장·야외·스튜디오 유형을 지정할 수 있습니다.

## 사용하는 방법

1. `/admin`에서 새 컬렉션을 만듭니다.
2. 촬영 유형과 장소를 고릅니다.
3. 행사에는 사람별 폴더를 만들고, 개인 세션에는 컬렉션 모델 정보를 입력합니다.
4. 사진과 정보를 확인한 뒤 공개로 전환합니다.

## 사용 예시·참고

예: 코믹월드에서 여러 사람을 촬영한 사진은 행사로, 행사 중 따로 진행한 한 팀 촬영은 개인 세션으로 만들고 관련 행사를 연결합니다.

[선택 업데이트 목록](../../updates/README.md)에서 관련 개선 기능도 확인할 수 있습니다.
