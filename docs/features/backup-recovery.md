# 휴지통·백업·복구

[전체 기능 안내](../../FEATURES.md) · [설치 안내](../../SETUP.md)

**제공 형태: 기본 포함** — 기준 배포본 `c1e54c3`에 포함된 기능입니다. 별도 선택 업데이트 ZIP은 없습니다.

삭제한 항목을 확인하고, 사이트의 사진과 메타데이터를 복구할 수 있도록 관리합니다.

## 할 수 있는 일

- 삭제 항목을 휴지통에서 확인하고 복구합니다.
- 보관기한이 지난 항목은 정리 대상이 됩니다.
- D1 메타데이터와 R2 사진을 별도 백업 버킷에 백업합니다.
- 관리자 화면에서 제공하는 백업 복원 절차를 사용할 수 있습니다.

## 사용하는 방법

1. 중요한 정리 작업 전 관리자 메뉴에서 백업 기능을 확인합니다.
2. 백업을 실행하고 완료 상태를 확인합니다.
3. 실수로 삭제했다면 먼저 휴지통에서 복구 가능 여부를 확인합니다.
4. 백업 복원이 필요한 경우 대상과 영향 범위를 확인한 뒤 진행합니다.

## 사용 예시·참고

코드 업데이트를 되돌리는 것과 사진·DB 백업을 복원하는 것은 별개입니다. 기능별 ZIP은 사진이나 컬렉션 데이터를 백업하지 않습니다.

[선택 업데이트 목록](../../updates/README.md)에서 관련 개선 기능도 확인할 수 있습니다.
