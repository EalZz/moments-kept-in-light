# 홈 섹션 순서 드래그

[전체 기능 안내](../../FEATURES.md) · [선택 업데이트 목록](../../updates/README.md)

**선택 업데이트** · 먼저 [Photo Zone과 가로 세션 카드](photo-zone-rails.md) 기능을 적용하세요.

관리자에서 `Events`, `Personal Sessions`, `Photo Zone`을 직접 옮겨 방문자 홈에 표시되는 순서를 정합니다.

## 사용 방법

1. 관리자 컬렉션 관리 화면에서 **홈 섹션 순서**를 찾습니다.
2. PC에서는 마우스로, 모바일에서는 손가락으로 행을 위·아래로 끌어 놓습니다. 키보드에서는 행에 포커스를 두고 위·아래 방향키를 사용합니다.
3. **저장**을 누르고 공개 홈을 확인합니다. 공개할 카드가 없는 섹션은 홈에서 숨겨집니다.

## 사용 예시

Photo Zone 행을 Events 위로 옮기면 공개된 Photo Zone 카드가 있을 때 해당 섹션부터 보입니다.
