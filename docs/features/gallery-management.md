# 사진 순서·대표 사진·공개 관리

[전체 기능 안내](../../FEATURES.md) · [설치 안내](../../SETUP.md)

**제공 형태: 기본 포함** — 기준 배포본 `c1e54c3`에 포함된 기능입니다. 별도 선택 업데이트 ZIP은 없습니다.

사진을 어떤 순서로 보여줄지, 어떤 사진을 대표로 쓸지, 컬렉션을 공개할지 관리합니다.

## 할 수 있는 일

- 사진 및 사람별 폴더 순서를 조정합니다.
- 컬렉션 대표 사진과 메인 슬라이드 관련 설정을 관리합니다.
- 여러 사진을 선택해 이동하거나 휴지통으로 보낼 수 있습니다.
- 컬렉션을 공개·비공개로 전환합니다.

## 사용하는 방법

1. `/admin`에서 대상 컬렉션을 엽니다.
2. 사진 순서와 대표 사진을 정합니다.
3. 필요하면 사진을 다른 폴더로 이동합니다.
4. 공개 상태를 확인하고 방문자 화면에서 결과를 확인합니다.

## 사용 예시·참고

예: 가장 먼저 보여주고 싶은 사진을 대표로 지정하고, 촬영 흐름에 맞게 나머지 사진의 순서를 정합니다.

[선택 업데이트 목록](../../updates/README.md)에서 관련 개선 기능도 확인할 수 있습니다.
