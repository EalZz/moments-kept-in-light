# 모델·작품·캐릭터 탐색과 검색

[전체 기능 안내](../../FEATURES.md) · [설치 안내](../../SETUP.md)

**제공 형태: 기본 포함** — 기준 배포본 `c1e54c3`에 포함된 기능입니다. 별도 선택 업데이트 ZIP은 없습니다.

행사 이름을 몰라도 모델이나 작품·캐릭터를 기준으로 사진을 찾을 수 있습니다.

## 할 수 있는 일

- 컬렉션·모델·작품/캐릭터·전체 사진의 탐색 경로를 제공합니다.
- 검색에서 행사·모델·작품·캐릭터 정보를 찾습니다.
- 관리자는 검색 별칭을 등록해 통칭으로도 찾게 할 수 있습니다.
- 모델 계정이 바뀐 경우 옛 계정과 새 계정을 연결하는 핸들 별칭을 관리할 수 있습니다.

## 사용하는 방법

1. 관리자에서 사진의 모델 계정·캐릭터·작품 정보를 입력합니다.
2. 필요한 경우 검색 별칭이나 계정 변경 연결을 등록합니다.
3. 방문자 화면에서 검색과 모델·작품 목록을 확인합니다.

## 사용 예시·참고

예: 작품 정식 이름과 함께 자주 쓰는 줄임말을 검색 별칭으로 등록합니다. 검색 별칭과 계정 변경 연결은 목적이 다른 설정입니다.

[선택 업데이트 목록](../../updates/README.md)에서 관련 개선 기능도 확인할 수 있습니다.
