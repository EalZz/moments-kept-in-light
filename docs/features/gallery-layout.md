# 갤러리 배치 개선

[전체 기능 안내](../../FEATURES.md) · [선택 업데이트 목록](../../updates/README.md)

**종류: 갤러리 표시 / 제공 형태: 선택 업데이트 1.0.0**

모바일의 홀수 세로 사진과 가로·세로 혼합 사진을 정돈하고, 데스크톱에서 적은 사진도 가운데 보여주고 싶을 때 사용합니다.

## 어떤 기능인가요?

| 사진 구성 | 업데이트 후 배치 |
|---|---|
| 모바일 세로 3장 | 첫 장을 크게, 나머지 두 장을 한 줄에 표시 |
| 모바일 세로 5장 | 큰 첫 장 + 두 장 + 두 장 |
| 모바일 가로·세로 혼합 | 가로 사진은 한 장씩, 이어지는 세로 사진은 묶음에 맞춰 배치 |
| 데스크톱 모델 그룹 1~2장 | 중앙에 배치하고 크기를 조정 |

모바일에서는 세로 사진이 연속된 묶음마다 홀수 여부를 판단합니다. 사진 순서와 비율을 보존하며 라이트박스도 같은 순서로 열립니다.

## 화면에서 사용하는 방법

1. 업데이트 적용 후 사진이 있는 행사·모델 갤러리를 엽니다.
2. 모바일 폭에서 세로 사진 3장·5장과 가로 사진이 섞인 구성을 확인합니다.
3. 데스크톱에서 1~2장인 모델 그룹의 정렬을 확인합니다.

## 적용 전 확인

별도 선행 업데이트가 없습니다. 이 기능만 선택해 적용할 수 있습니다.

새 사진을 추가하거나 원본 파일을 변경하는 기능이 아닙니다. 개인 세션의 별도 에디토리얼 갤러리 전체를 이 배치로 바꾸지는 않습니다.

검증 기준은 `c1e54c3` 배포 계열입니다. 다른 버전이나 개인 수정이 있으면 적용 전에 검사하거나 차이를 비교해야 합니다.
