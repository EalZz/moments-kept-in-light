# 개인 세션 카드와 대표 사진 구도

[전체 기능 안내](../../FEATURES.md) · [선택 업데이트 목록](../../updates/README.md)

**선택 업데이트** · 먼저 [사람별 모델 표시 이름](model-display-names.md) 기능을 적용하세요.

개인 세션을 메인에서 가로형 카드로 보여줍니다. 관리자에서 원본 사진의 사용할 영역을 직접 고르고, 카드에 적용되는 블러와 텍스트를 기기별로 확인합니다.

## 사용 방법

1. 관리자에서 개인 세션을 열고, 사진 목록의 **대표** 버튼으로 카드에 쓸 사진을 지정합니다.
2. 화면 상단 **카드 영역 편집**을 열고 `1:1` 또는 `4:5`를 선택합니다. 박스 위치와 **영역 크기**를 조절합니다.
3. **PC · 3:2**와 **모바일 · 16:9** 미리보기에서 사진·블러·텍스트를 확인한 뒤 **저장**을 누릅니다.
4. 메인 카드에서 닉네임 한 줄과 작품명·캐릭터명을 확인합니다. 구도를 지정하기 전에는 대표 사진 전체가 표시됩니다.

## 사용 예시

세로 인물 사진에서 얼굴과 의상이 함께 보이는 4:5 영역을 골라 두 비율의 카드에 같은 구도를 적용할 수 있습니다.
